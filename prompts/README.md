# Milestone prompts

This directory contains temporary handoff prompts for unfinished platform
milestones.

A prompt may define a bounded objective, required inputs, stopping conditions,
and completion report. It should link to the authoritative briefs instead of
copying their requirements. If a prompt conflicts with a brief, the brief wins.

Completed prompts are removed from this directory. Git history retains their
provenance; keeping obsolete construction instructions active creates another
source of truth.

There are currently no active milestone prompts. The V0 base starter has been
built and its Cloudflare/vinext plus Keystatic deployment path has passed the
end-to-end acceptance test.
